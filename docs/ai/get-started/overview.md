# Overview

AI Tools connects ONLYOFFICE editors to an AI provider, such as OpenAI or DeepSeek, or to a model running on your own server. It adds AI Chat, summarization, translation, grammar and spelling checks, Quick AI Actions, AI assistants, and the inline AI agent to the document, spreadsheet, presentation, and PDF editors.

:::note
AI Tools no longer supports adding your own AI tools (functions). To change how AI Tools works, use the settings, custom providers, and MCP servers described in the guides below.
:::

## What you can do

- **[Set up AI Tools](https://api.onlyoffice.com/ai-plugin-docs-update/docs/ai/guides/ai-plugin.md)**: connect an AI model, assign models to tasks, and add MCP servers and web search.
- **[Configure AI providers for all users](https://api.onlyoffice.com/ai-plugin-docs-update/docs/ai/guides/server-ai-providers.md)**: connect models once in the Admin Panel so that users do not have to set up anything.
- **[Add a custom provider](https://api.onlyoffice.com/ai-plugin-docs-update/docs/ai/guides/custom-providers.md)**: connect a provider that is not in the list.
- **[Use the AI agent](https://api.onlyoffice.com/ai-plugin-docs-update/docs/ai/guides/ai-agent.md)**: run editing tasks with natural language commands right in the document.
- **[Convert VBA macros](https://api.onlyoffice.com/ai-plugin-docs-update/docs/ai/guides/converting-vba-macros.md)**: turn VBA code into JavaScript macros with AI Tools.
- **[Run a local model with Ollama](https://api.onlyoffice.com/ai-plugin-docs-update/docs/ai/guides/configuring-ollama-with-cors.md)**: keep requests on your own machine or server.
