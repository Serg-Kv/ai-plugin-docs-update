# GetSelectedOleObjects

Returns an array of the selected OLE objects.

## Syntax

```javascript
expression.GetSelectedOleObjects();
```

`expression` - A variable that represents an [Api](https://api.onlyoffice.com/ai-plugin-docs-update/docs/plugins/interacting-with-editors/document-api.md) class.

## Parameters

This method doesn't have any parameters.

## Returns

[OLEProperties](https://api.onlyoffice.com/ai-plugin-docs-update/docs/plugins/interacting-with-editors/document-api/Enumeration/OLEProperties.md)[]

## Example

```javascript
window.Asc.plugin.executeMethod ("GetSelectedOleObjects");
```
