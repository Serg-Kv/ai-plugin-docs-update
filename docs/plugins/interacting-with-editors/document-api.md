# Document API

The Document API lists the methods and events a plugin can use when working with a text document in ONLYOFFICE Docs. To work with the document content directly, such as paragraphs and tables, run Office API code in `callCommand`. See [Document API](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api.md).
