# Changelog

The list of changes for ONLYOFFICE Document Builder.

## Version 10.0

- Added the PDF editing support. The [OpenFile](https://api.onlyoffice.com/ai-plugin-docs-update/docs/document-builder/builder-framework/CDocBuilder/OpenFile.md#opening-pdf-files) method opens a PDF form created in ONLYOFFICE in the document editor and any other PDF file in the PDF editor, where the full [PDF API](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/pdf-api.md) is available.
- Added the `m_sPassword` parameter to the [OpenFile](https://api.onlyoffice.com/ai-plugin-docs-update/docs/document-builder/builder-framework/CDocBuilder/OpenFile.md#opening-pdf-files) method for opening password-protected PDF files.
