# ApiFormRoles

Class representing a collection of form roles.

## Methods

The following table lists the available methods.

| Method | Returns | Description |
| ------ | ------- | ----------- |
| [Add](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/form-api/ApiFormRoles/Methods/Add.md) | boolean | Adds a new form role. |
| [GetAllRoles](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/form-api/ApiFormRoles/Methods/GetAllRoles.md) | string[] | Lists all available roles. |
| [GetCount](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/form-api/ApiFormRoles/Methods/GetCount.md) | number | Returns a number of form roles. |
| [GetRoleColor](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/form-api/ApiFormRoles/Methods/GetRoleColor.md) | null \| Object | Returns the RGB color of the specified role. |
| [HaveRole](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/form-api/ApiFormRoles/Methods/HaveRole.md) | boolean | Checks if a role with the specified name exists. |
| [MoveDown](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/form-api/ApiFormRoles/Methods/MoveDown.md) | boolean | Moves a role down in filling order. |
| [MoveUp](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/form-api/ApiFormRoles/Methods/MoveUp.md) | boolean | Moves a role up in filling order. |
| [Remove](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/form-api/ApiFormRoles/Methods/Remove.md) | boolean | Removes a role with the specified name. |
| [SetRoleColor](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/form-api/ApiFormRoles/Methods/SetRoleColor.md) | boolean | Sets the color for the specified role. |
