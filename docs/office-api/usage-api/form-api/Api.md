# Api

The main class of the Form API. Use it to create forms: text fields, combo boxes, checkboxes and radio buttons, date fields, picture forms, signature forms, and complex fields.

## Methods

The following table lists the available methods.

| Method | Returns | Description |
| ------ | ------- | ----------- |
| [ConvertDocument](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/form-api/Api/Methods/ConvertDocument.md) | string | Converts a document to Markdown or HTML text. |
| [CreateCheckBoxForm](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/form-api/Api/Methods/CreateCheckBoxForm.md) | [ApiCheckBoxForm](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/form-api/ApiCheckBoxForm.md) | Creates a checkbox / radio button with the specified checkbox / radio button properties. |
| [CreateComboBoxForm](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/form-api/Api/Methods/CreateComboBoxForm.md) | [ApiComboBoxForm](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/form-api/ApiComboBoxForm.md) | Creates a combo box / dropdown list with the specified combo box / dropdown list properties. |
| [CreateComplexForm](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/form-api/Api/Methods/CreateComplexForm.md) | [ApiComplexForm](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/form-api/ApiComplexForm.md) | Creates a complex form with the specified complex form properties. |
| [CreateDateForm](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/form-api/Api/Methods/CreateDateForm.md) | [ApiDateForm](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/form-api/ApiDateForm.md) | Creates a date form with the specified date form properties. |
| [CreatePictureForm](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/form-api/Api/Methods/CreatePictureForm.md) | [ApiPictureForm](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/form-api/ApiPictureForm.md) | Creates a picture form with the specified picture form properties. |
| [CreateSignatureForm](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/form-api/Api/Methods/CreateSignatureForm.md) | [ApiSignatureForm](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/form-api/ApiSignatureForm.md) | Creates a signature form with the specified form properties. |
| [CreateTextForm](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/form-api/Api/Methods/CreateTextForm.md) | [ApiTextForm](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/form-api/ApiTextForm.md) | Creates a text field with the specified text field properties. |
| [ReplaceTextSmart](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/form-api/Api/Methods/ReplaceTextSmart.md) | boolean | Replaces each paragraph (or text in cell) in the select with the corresponding text from an array of strings. |
