# ApiChartSeries

Class representing a chart series.

## Methods

The following table lists the available methods.

| Method | Returns | Description |
| ------ | ------- | ----------- |
| [ChangeChartType](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/pdf-api/ApiChartSeries/Methods/ChangeChartType.md) | boolean | Tries to change the series type. |
| [GetChartType](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/pdf-api/ApiChartSeries/Methods/GetChartType.md) | [ChartTypeLegacy](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/pdf-api/Enumeration/ChartTypeLegacy.md) | Returns a chart type of the current series. |
| [GetClassType](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/pdf-api/ApiChartSeries/Methods/GetClassType.md) | "chartSeries" | Returns a type of the ApiChartSeries class. |
| [GetType](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/pdf-api/ApiChartSeries/Methods/GetType.md) | [ChartType](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/pdf-api/Enumeration/ChartType.md) | Returns a chart type of the current series using the chart type names from the \{@link ChartType\} enumeration. |
