# FreeTextCallout

FreeText callout coordinates (Array of 3 points).

## Type

[Point](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/pdf-api/Enumeration/Point.md)[]

## Properties

| Name | Type | Description |
| ---- | ---- | ----------- |
| 0 | [Point](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/pdf-api/Enumeration/Point.md) | The starting point of the callout. |
| 1 | [Point](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/pdf-api/Enumeration/Point.md) | The knee/bend point of the callout. |
| 2 | [Point](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/pdf-api/Enumeration/Point.md) | The end point attached to the textbox. |
