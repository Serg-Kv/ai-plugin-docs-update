# GetAction

Gets the action executed when the link is clicked. Changes to the returned action update the link.

## Syntax

```javascript
expression.GetAction();
```

`expression` - A variable that represents an [ApiLinkAnnotation](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/pdf-api/ApiLinkAnnotation.md) class.

## Parameters

This method doesn't have any parameters.

## Returns

[ApiBaseAction](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/pdf-api/ApiBaseAction.md) \| null \| undefined
