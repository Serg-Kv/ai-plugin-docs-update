# RemoveAllElements

Removes all the elements from the current rich content.

:::note
When all elements are removed, a new empty rich paragraph is automatically created.
:::

## Syntax

```javascript
expression.RemoveAllElements();
```

`expression` - A variable that represents an [ApiRichContent](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/pdf-api/ApiRichContent.md) class.

## Parameters

This method doesn't have any parameters.

## Returns

boolean
