# ApiRichContent

Class representing a rich content.

## Methods

The following table lists the available methods.

| Method | Returns | Description |
| ------ | ------- | ----------- |
| [AddElement](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/pdf-api/ApiRichContent/Methods/AddElement.md) | boolean | Adds a rich paragraph using its position in rich content. |
| [GetClassType](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/pdf-api/ApiRichContent/Methods/GetClassType.md) | "richContent" | Returns a type of the ApiRichContent class. |
| [GetContent](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/pdf-api/ApiRichContent/Methods/GetContent.md) | [ApiRichParagraph](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/pdf-api/ApiRichParagraph.md)[] | Returns an array of rich paragraphs from the current rich content object. |
| [GetCurrentParagraph](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/pdf-api/ApiRichContent/Methods/GetCurrentParagraph.md) | [ApiRichParagraph](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/pdf-api/ApiRichParagraph.md) \| null \| undefined | Returns the current paragraph where the cursor is located. |
| [GetCurrentRun](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/pdf-api/ApiRichContent/Methods/GetCurrentRun.md) | [ApiRichRun](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/pdf-api/ApiRichRun.md) \| null \| undefined | Returns the current run where the cursor is located. |
| [GetElement](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/pdf-api/ApiRichContent/Methods/GetElement.md) | [ApiRichParagraph](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/pdf-api/ApiRichParagraph.md) \| null \| undefined | Returns an rich paragraph by its position in the content. |
| [GetElementsCount](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/pdf-api/ApiRichContent/Methods/GetElementsCount.md) | number | Returns a number of elements in the current document. |
| [GetText](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/pdf-api/ApiRichContent/Methods/GetText.md) | string | Returns the inner text of the current document content object. |
| [Push](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/pdf-api/ApiRichContent/Methods/Push.md) | boolean | Pushes a rich paragraph to a rich content. |
| [RemoveAllElements](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/pdf-api/ApiRichContent/Methods/RemoveAllElements.md) | boolean | Removes all the elements from the current rich content. |
| [RemoveElement](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/pdf-api/ApiRichContent/Methods/RemoveElement.md) | boolean | Removes an element using the position specified. |
