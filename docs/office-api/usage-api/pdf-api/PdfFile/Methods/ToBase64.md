# ToBase64

Returns pdf file in base64 format.

## Syntax

```javascript
expression.ToBase64();
```

`expression` - A variable that represents an [PdfFile](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/pdf-api/PdfFile.md) class.

## Parameters

This method doesn't have any parameters.

## Returns

Base64
