# ApiTablesOfFigures

Class representing the collection of all tables of figures in a document.

:::note
This functionality is available in paid ONLYOFFICE Docs editions.
:::

## Methods

The following table lists the available methods.

| Method | Returns | Description |
| ------ | ------- | ----------- |
| [Add](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTablesOfFigures/Methods/Add.md) | [ApiTableOfFigures](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableOfFigures.md) \| null | Adds a table of figures to the document and returns it. |
| [GetClassType](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTablesOfFigures/Methods/GetClassType.md) | "tablesOfFigures" | Returns a type of the ApiTablesOfFigures class. |
| [GetCount](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTablesOfFigures/Methods/GetCount.md) | number | Returns the number of tables of figures in the document. |
| [GetItem](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTablesOfFigures/Methods/GetItem.md) | [ApiTableOfFigures](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableOfFigures.md) \| null | Returns the table of figures at the specified position in the collection. |
| [GetParent](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTablesOfFigures/Methods/GetParent.md) | [ApiDocument](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiDocument.md) | Returns the document that owns this collection. |
