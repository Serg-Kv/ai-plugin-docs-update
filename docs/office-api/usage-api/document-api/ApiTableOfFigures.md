# ApiTableOfFigures

Class representing a table of figures.

:::note
This functionality is available in paid ONLYOFFICE Docs editions.
:::

## Methods

The following table lists the available methods.

| Method | Returns | Description |
| ------ | ------- | ----------- |
| [Delete](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableOfFigures/Methods/Delete.md) | boolean | Removes the table of figures from the document. |
| [GetCaption](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableOfFigures/Methods/GetCaption.md) | string \| null | Returns the caption label that the table of figures is built from (for example, "Figure"). |
| [GetClassType](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableOfFigures/Methods/GetClassType.md) | "tableOfFigures" | Returns a type of the ApiTableOfFigures class. |
| [GetIncludeLabel](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableOfFigures/Methods/GetIncludeLabel.md) | boolean | Returns whether the caption label and number are included in the table of figures entries. |
| [GetIncludePageNumbers](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableOfFigures/Methods/GetIncludePageNumbers.md) | boolean | Returns whether page numbers are shown in the table of figures. |
| [GetParent](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableOfFigures/Methods/GetParent.md) | [ApiDocument](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiDocument.md) \| null | Returns the document that contains the table of figures. |
| [GetRange](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableOfFigures/Methods/GetRange.md) | [ApiRange](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiRange.md) \| null | Returns a range that covers the entire table of figures. |
| [GetRightAlignPageNumbers](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableOfFigures/Methods/GetRightAlignPageNumbers.md) | boolean | Returns whether page numbers are right-aligned in the table of figures. |
| [GetUseHyperlinks](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableOfFigures/Methods/GetUseHyperlinks.md) | boolean | Returns whether entries are formatted as hyperlinks. |
| [SetCaption](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableOfFigures/Methods/SetCaption.md) | boolean | Sets the caption label that the table of figures is built from (for example, "Figure"). |
| [SetIncludeLabel](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableOfFigures/Methods/SetIncludeLabel.md) | boolean | Specifies whether the caption label and number are included in the table of figures entries. |
| [SetIncludePageNumbers](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableOfFigures/Methods/SetIncludePageNumbers.md) | boolean | Specifies whether page numbers are shown in the table of figures. |
| [SetPr](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableOfFigures/Methods/SetPr.md) | boolean | Applies the specified properties to the table of figures and rebuilds it. |
| [SetRightAlignPageNumbers](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableOfFigures/Methods/SetRightAlignPageNumbers.md) | boolean | Specifies whether page numbers are right-aligned in the table of figures. |
| [SetUseHyperlinks](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableOfFigures/Methods/SetUseHyperlinks.md) | boolean | Specifies whether entries are formatted as hyperlinks. |
| [Update](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableOfFigures/Methods/Update.md) | boolean | Updates the table of figures. |
