# ApiUniColor

Class representing a base class for color types.

## Methods

The following table lists the available methods.

| Method | Returns | Description |
| ------ | ------- | ----------- |
| [GetClassType](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiUniColor/Methods/GetClassType.md) | "uniColor" | Returns a type of the ApiUniColor class. |
| [GetRGB](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiUniColor/Methods/GetRGB.md) | number | Returns a color value in RGB format. |
| [ToJSON](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiUniColor/Methods/ToJSON.md) | JSON | Converts the ApiUniColor object into the JSON object. |
