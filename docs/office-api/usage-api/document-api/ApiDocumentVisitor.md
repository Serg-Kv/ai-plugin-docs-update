# ApiDocumentVisitor

Class representing a document visitor.

:::note
This functionality is available in paid ONLYOFFICE Docs editions.
:::

## Methods

The following table lists the available methods.

| Method | Returns | Description |
| ------ | ------- | ----------- |
| [Stop](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiDocumentVisitor/Methods/Stop.md) | boolean | Stops the traversal. No further hooks are called after the current one returns. |
