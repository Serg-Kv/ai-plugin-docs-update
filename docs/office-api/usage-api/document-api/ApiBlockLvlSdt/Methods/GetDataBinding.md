# GetDataBinding

Retrieves the data binding of the content control.

## Syntax

```javascript
expression.GetDataBinding();
```

`expression` - A variable that represents an [ApiBlockLvlSdt](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiBlockLvlSdt.md) class.

## Parameters

This method doesn't have any parameters.

## Returns

[XmlMapping](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/Enumeration/XmlMapping.md) \| null \| undefined
