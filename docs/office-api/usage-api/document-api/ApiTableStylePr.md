# ApiTableStylePr

Class representing a set of formatting properties which shall be conditionally applied to the parts of a table which match the requirement specified on the `Type`.

## Methods

The following table lists the available methods.

| Method | Returns | Description |
| ------ | ------- | ----------- |
| [GetClassType](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableStylePr/Methods/GetClassType.md) | "tableStylePr" | Returns a type of the ApiTableStylePr class. |
| [GetParaPr](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableStylePr/Methods/GetParaPr.md) | [ApiParaPr](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiParaPr.md) | Returns a set of the paragraph properties which will be applied to all the paragraphs within a table which match the conditional formatting type. |
| [GetTableCellPr](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableStylePr/Methods/GetTableCellPr.md) | [ApiTableCellPr](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableCellPr.md) | Returns a set of the table cell properties which will be applied to all the cells within a table which match the conditional formatting type. |
| [GetTablePr](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableStylePr/Methods/GetTablePr.md) | [ApiTablePr](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTablePr.md) | Returns a set of the table properties which will be applied to all the regions within a table which match the conditional formatting type. |
| [GetTableRowPr](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableStylePr/Methods/GetTableRowPr.md) | [ApiTableRowPr](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableRowPr.md) | Returns a set of the table row properties which will be applied to all the rows within a table which match the conditional formatting type. |
| [GetTextPr](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableStylePr/Methods/GetTextPr.md) | [ApiTextPr](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTextPr.md) | Returns a set of the text run properties which will be applied to all the text runs within the table which match the conditional formatting type. |
| [GetType](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableStylePr/Methods/GetType.md) | [TableStyleOverrideType](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/Enumeration/TableStyleOverrideType.md) | Returns a type of the current table conditional style. |
| [SetParaPr](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableStylePr/Methods/SetParaPr.md) | [ApiTableStylePr](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableStylePr.md) | Sets the paragraph properties to the current table style properties. |
| [SetTableCellPr](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableStylePr/Methods/SetTableCellPr.md) | [ApiTableStylePr](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableStylePr.md) | Sets the table cell properties to the current table style properties. |
| [SetTablePr](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableStylePr/Methods/SetTablePr.md) | [ApiTableStylePr](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableStylePr.md) | Sets the table properties to the current table style properties. |
| [SetTableRowPr](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableStylePr/Methods/SetTableRowPr.md) | [ApiTableStylePr](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableStylePr.md) | Sets the table row properties to the current table style properties. |
| [SetTextPr](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableStylePr/Methods/SetTextPr.md) | [ApiTableStylePr](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableStylePr.md) | Sets the text properties to the current table style properties. |
| [ToJSON](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableStylePr/Methods/ToJSON.md) | JSON | Converts the ApiTableStylePr object into the JSON object. |
