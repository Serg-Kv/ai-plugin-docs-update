# ApiContentControlList

Class representing a list of values of the combo box / drop-down list content control.

## Methods

The following table lists the available methods.

| Method | Returns | Description |
| ------ | ------- | ----------- |
| [Add](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiContentControlList/Methods/Add.md) | boolean | Adds a new value to the combo box / drop-down list content control. |
| [Clear](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiContentControlList/Methods/Clear.md) | boolean | Clears a list of values of the combo box / drop-down list content control. |
| [GetAllItems](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiContentControlList/Methods/GetAllItems.md) | [ApiContentControlListEntry](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiContentControlListEntry.md)[] | Returns a collection of items (the ApiContentControlListEntry objects) of the combo box / drop-down list content control. |
| [GetClassType](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiContentControlList/Methods/GetClassType.md) | "contentControlList" | Returns a type of the ApiContentControlList class. |
| [GetElementsCount](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiContentControlList/Methods/GetElementsCount.md) | number | Returns a number of items of the combo box / drop-down list content control. |
| [GetItem](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiContentControlList/Methods/GetItem.md) | [ApiContentControlListEntry](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiContentControlListEntry.md) | Returns an item of the combo box / drop-down list content control by the position specified in the request. |
| [GetParent](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiContentControlList/Methods/GetParent.md) | [ApiInlineLvlSdt](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiInlineLvlSdt.md) \| [ApiBlockLvlSdt](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiBlockLvlSdt.md) | Returns a parent of the combo box / drop-down list content control. |
