# ApiContentControlListEntry

Class representing an entry of the combo box / drop-down list content control.

## Methods

The following table lists the available methods.

| Method | Returns | Description |
| ------ | ------- | ----------- |
| [Delete](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiContentControlListEntry/Methods/Delete.md) | boolean | Deletes the specified item in the combo box / drop-down list content control. |
| [GetClassType](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiContentControlListEntry/Methods/GetClassType.md) | "contentControlList" | Returns a type of the ApiContentControlListEntry class. |
| [GetIndex](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiContentControlListEntry/Methods/GetIndex.md) | number | Returns an index of the content control list item in the combo box / drop-down list content control. |
| [GetParent](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiContentControlListEntry/Methods/GetParent.md) | [ApiContentControlList](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiContentControlList.md) | Returns a parent of the content control list item in the combo box / drop-down list content control. |
| [GetText](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiContentControlListEntry/Methods/GetText.md) | string | Returns a String that represents the display text of a list item for the combo box / drop-down list content control. |
| [GetValue](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiContentControlListEntry/Methods/GetValue.md) | string | Returns a String that represents the value of a list item for the combo box / drop-down list content control. |
| [MoveDown](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiContentControlListEntry/Methods/MoveDown.md) | boolean | Moves the current item in the parent combo box / drop-down list content control down one element, so that it is after the item that originally followed it. |
| [MoveUp](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiContentControlListEntry/Methods/MoveUp.md) | boolean | Moves the current item in the parent combo box / drop-down list content control up one element. |
| [Select](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiContentControlListEntry/Methods/Select.md) | boolean | Selects the list entry in the combo box / drop-down list content control and sets the text of the content control to the selected item value. |
| [SetIndex](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiContentControlListEntry/Methods/SetIndex.md) | boolean | Sets an index to the content control list item in the combo box / drop-down list content control. |
| [SetText](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiContentControlListEntry/Methods/SetText.md) | boolean | Sets a String that represents the display text of a list item for the combo box / drop-down list content control. |
| [SetValue](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiContentControlListEntry/Methods/SetValue.md) | boolean | Sets a String that represents the value of a list item for the combo box / drop-down list content control. |
