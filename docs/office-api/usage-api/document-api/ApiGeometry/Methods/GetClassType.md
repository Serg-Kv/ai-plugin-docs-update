# GetClassType

Returns a type of the ApiGeometry class.

## Syntax

```javascript
expression.GetClassType();
```

`expression` - A variable that represents an [ApiGeometry](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiGeometry.md) class.

## Parameters

This method doesn't have any parameters.

## Returns

"geometry"
