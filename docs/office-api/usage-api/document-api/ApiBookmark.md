# ApiBookmark

Class representing a bookmark in the document.

## Methods

The following table lists the available methods.

| Method | Returns | Description |
| ------ | ------- | ----------- |
| [Delete](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiBookmark/Methods/Delete.md) | boolean | Deletes the current bookmark from the document. |
| [GetName](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiBookmark/Methods/GetName.md) | string | Returns the bookmark name. |
| [GetRange](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiBookmark/Methods/GetRange.md) | [ApiRange](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiRange.md) | Returns the bookmark range. |
| [GetText](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiBookmark/Methods/GetText.md) | string | Returns the bookmark text. |
| [GoTo](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiBookmark/Methods/GoTo.md) | boolean | Moves a cursor to the current bookmark. |
| [Select](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiBookmark/Methods/Select.md) | boolean | Selects the current bookmark. |
| [SetName](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiBookmark/Methods/SetName.md) | boolean | Changes the bookmark name. |
| [SetText](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiBookmark/Methods/SetText.md) | boolean | Sets the bookmark text. |
