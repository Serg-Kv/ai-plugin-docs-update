# AddParagraph

Creates a new paragraph and appends it to the end of the document content.

## Syntax

```javascript
expression.AddParagraph();
```

`expression` - A variable that represents an [ApiDocumentContent](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiDocumentContent.md) class.

## Parameters

This method doesn't have any parameters.

## Returns

[ApiParagraph](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiParagraph.md)
