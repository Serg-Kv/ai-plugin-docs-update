# ApiTablesOfContents

Class representing the collection of all tables of contents in a document.

:::note
This functionality is available in paid ONLYOFFICE Docs editions.
:::

## Methods

The following table lists the available methods.

| Method | Returns | Description |
| ------ | ------- | ----------- |
| [Add](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTablesOfContents/Methods/Add.md) | [ApiTableOfContents](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableOfContents.md) \| null | Adds a table of contents to the document and returns it. |
| [GetClassType](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTablesOfContents/Methods/GetClassType.md) | "tablesOfContents" | Returns a type of the ApiTablesOfContents class. |
| [GetCount](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTablesOfContents/Methods/GetCount.md) | number | Returns the number of tables of contents in the document. |
| [GetItem](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTablesOfContents/Methods/GetItem.md) | [ApiTableOfContents](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableOfContents.md) \| null | Returns the table of contents at the specified position in the collection. |
| [GetParent](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTablesOfContents/Methods/GetParent.md) | [ApiDocument](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiDocument.md) | Returns the document that owns this collection. |
