# ApiTableOfContents

Class representing a table of contents.

:::note
This functionality is available in paid ONLYOFFICE Docs editions.
:::

## Methods

The following table lists the available methods.

| Method | Returns | Description |
| ------ | ------- | ----------- |
| [Delete](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableOfContents/Methods/Delete.md) | boolean | Removes the table of contents from the document. |
| [GetClassType](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableOfContents/Methods/GetClassType.md) | "tableOfContents" | Returns a type of the ApiTableOfContents class. |
| [GetIncludePageNumbers](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableOfContents/Methods/GetIncludePageNumbers.md) | boolean | Returns whether page numbers are shown in the table of contents. |
| [GetLowerHeadingLevel](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableOfContents/Methods/GetLowerHeadingLevel.md) | number | Returns the lowest (innermost) heading level included in the table of contents. |
| [GetParent](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableOfContents/Methods/GetParent.md) | [ApiDocument](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiDocument.md) \| null | Returns the document that contains the table of contents. |
| [GetRange](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableOfContents/Methods/GetRange.md) | [ApiRange](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiRange.md) \| null | Returns a range that covers the entire table of contents. |
| [GetRightAlignPageNumbers](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableOfContents/Methods/GetRightAlignPageNumbers.md) | boolean | Returns whether page numbers are right-aligned in the table of contents. |
| [GetUpperHeadingLevel](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableOfContents/Methods/GetUpperHeadingLevel.md) | number | Returns the highest (outermost) heading level included in the table of contents. |
| [GetUseHyperlinks](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableOfContents/Methods/GetUseHyperlinks.md) | boolean | Returns whether entries are formatted as hyperlinks. |
| [SetIncludePageNumbers](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableOfContents/Methods/SetIncludePageNumbers.md) | boolean | Specifies whether page numbers are shown in the table of contents. |
| [SetLowerHeadingLevel](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableOfContents/Methods/SetLowerHeadingLevel.md) | boolean | Sets the lowest (innermost) heading level included in the table of contents. |
| [SetPr](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableOfContents/Methods/SetPr.md) | boolean | Applies the specified properties to the table of contents and rebuilds it. |
| [SetRightAlignPageNumbers](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableOfContents/Methods/SetRightAlignPageNumbers.md) | boolean | Specifies whether page numbers are right-aligned in the table of contents. |
| [SetUpperHeadingLevel](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableOfContents/Methods/SetUpperHeadingLevel.md) | boolean | Sets the highest (outermost) heading level included in the table of contents. |
| [SetUseHyperlinks](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableOfContents/Methods/SetUseHyperlinks.md) | boolean | Specifies whether entries are formatted as hyperlinks. |
| [Update](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiTableOfContents/Methods/Update.md) | boolean | Updates the table of contents. |
