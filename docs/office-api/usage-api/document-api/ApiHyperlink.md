# ApiHyperlink

Class representing a Paragraph hyperlink.

## Methods

The following table lists the available methods.

| Method | Returns | Description |
| ------ | ------- | ----------- |
| [GetClassType](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiHyperlink/Methods/GetClassType.md) | "hyperlink" | Returns a type of the ApiHyperlink class. |
| [GetDisplayedText](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiHyperlink/Methods/GetDisplayedText.md) | string | Returns the hyperlink display text. |
| [GetElement](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiHyperlink/Methods/GetElement.md) | [ParagraphContent](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/Enumeration/ParagraphContent.md) \| null \| undefined | Returns the hyperlink element using the position specified. |
| [GetElementsCount](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiHyperlink/Methods/GetElementsCount.md) | number | Returns a number of elements in the current hyperlink. |
| [GetLinkedText](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiHyperlink/Methods/GetLinkedText.md) | string | Returns the hyperlink address. |
| [GetParent](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiHyperlink/Methods/GetParent.md) | [ParagraphLikeContainer](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/Enumeration/ParagraphLikeContainer.md) \| null \| undefined | Returns the parent element (a paragraph or an inline content control) that directly contains the current hyperlink. |
| [GetPosInParent](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiHyperlink/Methods/GetPosInParent.md) | Number | Returns the position (index) of the current hyperlink within its parent element. |
| [GetRange](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiHyperlink/Methods/GetRange.md) | [ApiRange](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiRange.md) | Returns a Range object that represents the document part contained in the specified hyperlink. |
| [GetScreenTipText](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiHyperlink/Methods/GetScreenTipText.md) | string | Returns the screen tip text of the hyperlink. |
| [SetDefaultStyle](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiHyperlink/Methods/SetDefaultStyle.md) | boolean | Sets the default hyperlink style. |
| [SetDisplayedText](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiHyperlink/Methods/SetDisplayedText.md) | boolean | Sets the hyperlink display text. |
| [SetLink](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiHyperlink/Methods/SetLink.md) | boolean | Sets the hyperlink address. |
| [SetScreenTipText](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiHyperlink/Methods/SetScreenTipText.md) | boolean | Sets the screen tip text of the hyperlink. |
| [ToJSON](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/document-api/ApiHyperlink/Methods/ToJSON.md) | JSON | Converts the ApiHyperlink object into the JSON object. |
