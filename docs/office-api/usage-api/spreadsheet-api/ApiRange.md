# ApiRange

Class representing a range.

## Properties

| Name | Type | Description |
| ---- | ---- | ----------- |
| Address | string | Returns the range address. |
| AlignHorizontal | 'left' \| 'right' \| 'center' \| 'justify' | Sets the text horizontal alignment to the current cell range. |
| AlignVertical | 'center' \| 'bottom' \| 'top' \| 'distributed' \| 'justify' | Sets the text vertical alignment to the current cell range. |
| Areas | [ApiAreas](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiAreas.md) | Returns a collection of the areas. |
| Bold | boolean | Sets the bold property to the text characters from the current cell or cell range. |
| Cells | [ApiRange](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiRange.md) | Returns a Range object that represents all the cells in the specified range or a specified cell. |
| CellsCount | number | Returns a number of cells in the current range. |
| Characters | [ApiCharacters](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiCharacters.md) | Returns the ApiCharacters object that represents a range of characters within the object text. Use the ApiCharacters object to format characters within a text string. |
| Col | number | Returns the column number for the selected cell. |
| Cols | [ApiRange](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiRange.md) | Returns the ApiRange object that represents the columns of the specified range. |
| ColumnWidth | number | Returns or sets the width of all the columns in the specified range measured in points. |
| Columns | [ApiRange](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiRange.md) | Returns the ApiRange object that represents the columns of the specified range. |
| ColumnsCount | number | Returns a number of columns in the current range. |
| Comments | [ApiComment](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiComment.md) \| null | Returns the ApiComment collection that represents all the comments from the specified worksheet. |
| Count | number | Returns the rows or columns count. |
| CurrentRegion | [ApiRange](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiRange.md) | Returns a range that represents the expanded range around the current range. |

| FontName | string | Sets the specified font family as the font name for the current cell range. |
| FontSize | number | Sets the font size (measured in points) to the characters of the current cell range. |
| FormatConditions | [ApiFormatConditions](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiFormatConditions.md) | Returns the collection of conditional formatting rules for the current range. |
| Formula | string \| string[][] | Returns a formula from the cell of the specified range or an array of formulas by rows from a range of several cells, or sets it to this cell. |
| FormulaArray | string \| null | Returns the array formula of the specified range or sets it to this range. |
| Height | number | Returns a value that represents the range height measured in points. |
| Hidden | boolean | Returns or sets the value hiding property. |
| Hyperlinks | [ApiHyperlink](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiHyperlink.md)[] | Returns an array of all the hyperlinks in the range. |
| Italic | boolean | Sets the italic property to the text characters in the current cell or cell range. |
| MergeArea | [ApiRange](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiRange.md) | Returns the cell or cell range from the merge area. |

| Orientation | [Angle](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/Enumeration/Angle.md) | Returns an angle to the current cell range. |

| ReadingOrder | 'context' \| 'ltr' \| 'rtl' | Sets the direction (reading order) of the text in the current cell range. |
| Row | number | Returns the row number for the selected cell. |

| Rows | [ApiRange](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiRange.md) | Returns the ApiRange object that represents the rows of the specified range. |

| Strikeout | boolean | Sets a value that indicates whether the contents of the current cell or cell range are displayed struck through. |
| Text | string | Returns the text from the first cell of the specified range or sets it to this cell. |
| Underline | 'none' \| 'single' \| 'singleAccounting' \| 'double' \| 'doubleAccounting' | Sets the type of underline applied to the font. |
| Validation | [ApiValidation](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiValidation.md) | Returns the ApiValidation class instance associated with this range. If no validation instance exists yet, it will be created. |
| Value | string | Returns a value from the first cell of the specified range or sets it to this cell. |
| Value2 | string | Returns the value2 (value without format) from the first cell of the specified range or sets it to this cell. |
| Width | number | Returns a value that represents the range width measured in points. |
| Worksheet | [ApiWorksheet](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiWorksheet.md) | Returns the ApiWorksheet object that represents the worksheet containing the specified range. |
| WrapText | boolean | Returns the information about the wrapping cell style or specifies whether the words in the cell must be wrapped to fit the cell size or not. |
