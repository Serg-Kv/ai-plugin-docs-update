# ApiPage

Class representing the header and footer of a specific page type (even or first) of a worksheet.

## Properties

| Name | Type | Description |
| ---- | ---- | ----------- |
| CenterFooter | [ApiHeaderFooter](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiHeaderFooter.md) | Returns the center footer section of this page type. |
| CenterHeader | [ApiHeaderFooter](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiHeaderFooter.md) | Returns the center header section of this page type. |
| LeftFooter | [ApiHeaderFooter](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiHeaderFooter.md) | Returns the left footer section of this page type. |
| LeftHeader | [ApiHeaderFooter](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiHeaderFooter.md) | Returns the left header section of this page type. |
| RightFooter | [ApiHeaderFooter](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiHeaderFooter.md) | Returns the right footer section of this page type. |
| RightHeader | [ApiHeaderFooter](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiHeaderFooter.md) | Returns the right header section of this page type. |
