# ApiPivotFilters

Class representing a collection of pivot filters applied to a pivot field.

## Methods

The following table lists the available methods.

| Method | Returns | Description |
| ------ | ------- | ----------- |
| [Add](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiPivotFilters/Methods/Add.md) | None | Adds a new filter to the pivot field. |
