# ApiShd

Class representing the shading of text, a paragraph, a table or a table cell.

## Properties

| Name | Type | Description |
| ---- | ---- | ----------- |
| Color | [ApiColor](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiColor.md) | The shading color. |
| Type | [ShdType](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/Enumeration/ShdType.md) | The shading type: **"nil"** - no shading, **"clear"** - solid fill. |
