# Api

The main class of the Spreadsheet API. Use it to get the active workbook, worksheets, ranges, and the current selection, and to add worksheets, defined names, and custom functions.

## Properties

| Name | Type | Description |
| ---- | ---- | ----------- |
| ActiveSheet | [ApiWorksheet](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiWorksheet.md) | Returns an object that represents the active sheet. |
| ActiveWorkbook | [ApiWorkbook](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiWorkbook.md) | Returns an object that represents the active workbook. |
| AllComments | [ApiComment](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiComment.md)[] | Returns all comments from the current workbook including comments from all worksheets. |
| Comments | [ApiComment](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiComment.md)[] | Returns all comments related to the whole workbook. |
| FreezePanes | [FreezePaneType](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/Enumeration/FreezePaneType.md) | Returns or sets the type of freeze panes. |
| PivotTables | [ApiPivotTable](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiPivotTable.md)[] | Returns all pivot tables. |
| ReferenceStyle | [ReferenceStyle](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/Enumeration/ReferenceStyle.md) | Returns or sets the reference style. |
| Selection | [ApiRange](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiRange.md) | Returns an object that represents the selected range. |
| Sheets | [ApiWorksheet](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiWorksheet.md)[] | Returns the Sheets collection that represents all the sheets in the active workbook. |
| WorksheetFunction | [ApiWorksheetFunction](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiWorksheetFunction.md) | Returns an object that represents the function list. |
