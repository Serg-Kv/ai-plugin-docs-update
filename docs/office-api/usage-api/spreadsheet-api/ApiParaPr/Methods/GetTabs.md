# GetTabs

Returns the custom tab stops of the current paragraph.

## Syntax

```javascript
expression.GetTabs();
```

`expression` - A variable that represents an [ApiParaPr](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiParaPr.md) class.

## Parameters

This method doesn't have any parameters.

## Returns

[TabStop](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/Enumeration/TabStop.md)[]
