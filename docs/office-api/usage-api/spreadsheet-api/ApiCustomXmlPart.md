# ApiCustomXmlPart

Class representing a custom XML part.

## Methods

The following table lists the available methods.

| Method | Returns | Description |
| ------ | ------- | ----------- |
| [Delete](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiCustomXmlPart/Methods/Delete.md) | boolean | Deletes the XML from the custom XML manager. |
| [DeleteAttribute](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiCustomXmlPart/Methods/DeleteAttribute.md) | boolean | Deletes an attribute from the XML node at the specified XPath. |
| [DeleteElement](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiCustomXmlPart/Methods/DeleteElement.md) | boolean | Deletes an XML element at the specified XPath. |
| [GetAttribute](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiCustomXmlPart/Methods/GetAttribute.md) | string \| null | Returns an attribute from the XML node at the specified XPath. |
| [GetClassType](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiCustomXmlPart/Methods/GetClassType.md) | "customXmlPart" | Returns a type of the ApiCustomXmlPart class. |
| [GetId](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiCustomXmlPart/Methods/GetId.md) | string | Returns the ID of the custom XML part. |
| [GetNodes](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiCustomXmlPart/Methods/GetNodes.md) | [ApiCustomXmlNode](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiCustomXmlNode.md)[] | Retrieves nodes from custom XML based on the provided XPath. |
| [GetXml](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiCustomXmlPart/Methods/GetXml.md) | string | Retrieves the XML string from the custom XML part. |
| [InsertAttribute](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiCustomXmlPart/Methods/InsertAttribute.md) | boolean | Inserts an attribute into the XML node at the specified XPath. |
| [InsertElement](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiCustomXmlPart/Methods/InsertElement.md) | boolean | Inserts an XML element at the specified XPath. |
| [UpdateAttribute](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiCustomXmlPart/Methods/UpdateAttribute.md) | boolean | Updates an attribute of the XML node at the specified XPath. |
| [UpdateElement](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiCustomXmlPart/Methods/UpdateElement.md) | boolean | Updates an XML element at the specified XPath. |
