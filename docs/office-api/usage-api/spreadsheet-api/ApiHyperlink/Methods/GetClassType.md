# GetClassType

Returns a type of the ApiHyperlink class.

## Syntax

```javascript
expression.GetClassType();
```

`expression` - A variable that represents an [ApiHyperlink](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiHyperlink.md) class.

## Parameters

This method doesn't have any parameters.

## Returns

"hyperlink"
