# ApiWorksheet

Class representing a sheet.

## Properties

| Name | Type | Description |
| ---- | ---- | ----------- |
| Active | number | Makes the current sheet active. |
| ActiveCell | [ApiRange](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiRange.md) | Returns an object that represents an active cell. |

| Cells | [ApiRange](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiRange.md) | Returns ApiRange that represents all the cells on the worksheet (not just the cells that are currently in use). |
| Cols | [ApiRange](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiRange.md) | Returns ApiRange that represents all the cells of the columns range. |
| Comments | [ApiComment](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiComment.md)[] | Returns all comments from the current worksheet. |
| DefNames | [ApiName](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiName.md)[] | Returns an array of the ApiName objects. |
| FreezePanes | [ApiFreezePanes](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiFreezePanes.md) | Returns the freeze panes for the current worksheet. |

| Index | number | Returns a sheet index. |
| LeftMargin | number | Returns or sets the size of the sheet left margin measured in points. |
| Name | string | Returns or sets a name of the active sheet. |
| PageOrientation | [PageOrientation](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/Enumeration/PageOrientation.md) | Returns or sets the page orientation. |
| PageSetup | [ApiPageSetup](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiPageSetup.md) | Returns the page setup object for the current worksheet. |

| PrintHeadings | boolean | Returns or sets the page PrintHeadings property. |
| RightMargin | number | Returns or sets the size of the sheet right margin measured in points. |
