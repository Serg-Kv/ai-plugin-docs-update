# ApiHeaderFooter

Class representing a single header or footer section (left, center or right) of a page.

## Properties

| Name | Type | Description |
| ---- | ---- | ----------- |
| Text | string | Returns or sets the text of this header or footer section (may contain formatting codes such as &P, &D). |

## Methods

The following table lists the available methods.

| Method | Returns | Description |
| ------ | ------- | ----------- |
| [GetText](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiHeaderFooter/Methods/GetText.md) | string | Returns the text of this header or footer section. |
| [SetText](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiHeaderFooter/Methods/SetText.md) | boolean | Sets the text of this header or footer section, preserving the other two sections. |
