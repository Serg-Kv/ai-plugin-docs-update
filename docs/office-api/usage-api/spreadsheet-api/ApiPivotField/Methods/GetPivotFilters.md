# GetPivotFilters

Returns the collection of pivot filters applied to the specified pivot field.

## Syntax

```javascript
expression.GetPivotFilters();
```

`expression` - A variable that represents an [ApiPivotField](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiPivotField.md) class.

## Parameters

This method doesn't have any parameters.

## Returns

[ApiPivotFilters](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiPivotFilters.md)
