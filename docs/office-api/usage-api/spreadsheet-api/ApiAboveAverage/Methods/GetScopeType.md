# GetScopeType

Returns the scope type of the conditional formatting rule.

## Syntax

```javascript
expression.GetScopeType();
```

`expression` - A variable that represents an [ApiAboveAverage](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiAboveAverage.md) class.

## Parameters

This method doesn't have any parameters.

## Returns

[XlPivotConditionScope](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/Enumeration/XlPivotConditionScope.md)
