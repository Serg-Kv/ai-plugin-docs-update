# ApiName

Class representing a name.

## Properties

| Name | Type | Description |
| ---- | ---- | ----------- |
| Name | string | Sets a name to the active sheet. |
| RefersTo | string | Returns or sets a formula that the name is defined to refer to. |
| RefersToRange | [ApiRange](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiRange.md) | Returns the ApiRange object by reference. |

The following table lists the available methods.

| ------ | ------- | ----------- |
| [Delete](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiName/Methods/Delete.md) | boolean | Deletes the DefName object. |
