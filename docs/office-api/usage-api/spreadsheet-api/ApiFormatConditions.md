# ApiFormatConditions

Class representing a collection of format conditions.

## Properties

| Name | Type | Description |
| ---- | ---- | ----------- |
| Count | number | Returns the number of conditional formatting rules in the collection. |
| Parent | [ApiRange](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiRange.md) | Returns the parent range object associated with the current conditional formatting collection. |
