# ApiIconCriterion

| Name | Type | Description |
| ---- | ---- | ----------- |
| Icon | [XlIcon](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/Enumeration/XlIcon.md) | Returns or sets the icon of the icon criterion. |
| Index | number | Returns the index of the icon criterion in the collection. |
| Operator | string | Returns or sets the comparison operator of the icon criterion. |
| Type | [XlConditionValueTypes](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/Enumeration/XlConditionValueTypes.md) | Returns or sets the condition value type of the icon criterion. |
| Value | string \| number | Returns or sets the threshold value of the icon criterion. |
