# GetPivotFilters

Returns the collection of pivot filters applied to the specified pivot field.

Inherited from [ApiPivotField.GetPivotFilters](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiPivotField/Methods/GetPivotFilters.md).

## Syntax

```javascript
expression.GetPivotFilters();
```

`expression` - A variable that represents an [ApiPivotDataField](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiPivotDataField.md) class.
