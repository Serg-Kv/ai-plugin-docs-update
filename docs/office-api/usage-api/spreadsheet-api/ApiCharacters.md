# ApiCharacters

Class representing characters in an object that contains text.

## Properties

| Name | Type | Description |
| ---- | ---- | ----------- |
| Caption | string | The text of the specified range of characters. |
| Count | number | The number of characters in the collection. |
| Font | [ApiFont](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiFont.md) | The font of the specified characters. |
| Parent | [ApiRange](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiRange.md) | The parent object of the specified characters. |
| Text | string | The string value representing the text of the specified range of characters. |
