# ApiSortFields

Class representing the collection of sort fields for a Sort object.

:::note
This functionality is available in paid ONLYOFFICE Docs editions.
:::

## Properties

| Name | Type | Description |
| ---- | ---- | ----------- |
| Count | number | Returns the number of sort fields in the collection. |
| Parent | [ApiSort](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiSort.md) | Returns the parent Sort object. |

## Methods

The following table lists the available methods.

| Method | Returns | Description |
| ------ | ------- | ----------- |
| [Add](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiSortFields/Methods/Add.md) | [ApiSortField](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiSortField.md) \| null | Adds a sort field to the collection. |
| [Add2](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiSortFields/Methods/Add2.md) | [ApiSortField](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiSortField.md) \| null | Adds a sort field with subfield support for linked data types (Stocks, Geography). |
| [Clear](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiSortFields/Methods/Clear.md) | None | Removes all sort fields from the collection. |
| [GetCount](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiSortFields/Methods/GetCount.md) | number | Returns the number of sort fields. |
| [GetParent](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiSortFields/Methods/GetParent.md) | [ApiSort](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiSort.md) | Returns the parent Sort object. |
| [Item](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiSortFields/Methods/Item.md) | [ApiSortField](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiSortField.md) \| null | Returns the sort field at the given 1-based index. |
