# ApiFreezePanes

Class representing freeze panes.

## Methods

The following table lists the available methods.

| Method | Returns | Description |
| ------ | ------- | ----------- |
| [FreezeAt](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiFreezePanes/Methods/FreezeAt.md) | None | Sets the frozen cells in the active worksheet view. |
| [FreezeColumns](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiFreezePanes/Methods/FreezeColumns.md) | None | Freezes the first column or columns of the current worksheet. |
| [FreezeRows](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiFreezePanes/Methods/FreezeRows.md) | None | Freezes the top row or rows of the current worksheet. |
| [GetLocation](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiFreezePanes/Methods/GetLocation.md) | [ApiRange](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiRange.md) \| null | Returns a range that describes the frozen cells in the active worksheet view. |
| [Unfreeze](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/spreadsheet-api/ApiFreezePanes/Methods/Unfreeze.md) | None | Removes all frozen panes in the current worksheet. |
