# ApiGeometry

Class representing the shape geometry.

## Methods

The following table lists the available methods.

| Method | Returns | Description |
| ------ | ------- | ----------- |
| [AddAdj](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiGeometry/Methods/AddAdj.md) | boolean | Adds a new adjustment parameter to the current geometry. |
| [AddConnectionPoint](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiGeometry/Methods/AddConnectionPoint.md) | boolean | Adds a connection point to the current geometry. |
| [AddGuide](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiGeometry/Methods/AddGuide.md) | boolean | Adds a guide (formula) to the current geometry. |
| [AddPath](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiGeometry/Methods/AddPath.md) | [ApiPath](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiPath.md) \| null | Adds a new path to the current geometry. |
| [GetAdjValue](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiGeometry/Methods/GetAdjValue.md) | number \| null | Returns the adjustment value by its name from the current geometry. |
| [GetClassType](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiGeometry/Methods/GetClassType.md) | "geometry" | Returns a type of the ApiGeometry class. |
| [GetPath](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiGeometry/Methods/GetPath.md) | [ApiPath](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiPath.md) | Returns a geometry path by its index. |
| [GetPathCount](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiGeometry/Methods/GetPathCount.md) | number | Returns the number of paths in the current geometry. |
| [GetPaths](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiGeometry/Methods/GetPaths.md) | [ApiPath](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiPath.md)[] | Returns all paths of the current geometry. |
| [GetPreset](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiGeometry/Methods/GetPreset.md) | [ShapeType](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/Enumeration/ShapeType.md) \| null \| undefined | Returns the name of the preset shape if the current geometry is based on a preset. |
| [IsCustom](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiGeometry/Methods/IsCustom.md) | boolean | Checks whether the current geometry is custom. |
| [SetAdjValue](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiGeometry/Methods/SetAdjValue.md) | None | Sets the specified adjustment parameter for the current geometry. |
| [SetTextRect](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiGeometry/Methods/SetTextRect.md) | boolean | Sets the text rectangle for the current geometry. |
