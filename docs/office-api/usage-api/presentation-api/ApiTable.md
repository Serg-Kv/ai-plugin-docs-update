| Name | Type | Description |
| ---- | ---- | ----------- |
| Cells | [ApiTableCell](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiTableCell.md)[][] | Returns all cells of the current table as a two-dimensional array indexed by [row][cell]. |
