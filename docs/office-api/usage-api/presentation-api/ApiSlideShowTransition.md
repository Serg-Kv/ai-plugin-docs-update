# ApiSlideShowTransition

Class representing a slide show transition.

## Properties

| Name | Type | Description |
| ---- | ---- | ----------- |
| AdvanceOnClick | boolean | Returns or sets whether the slide advances on mouse click. |
| AdvanceOnTime | boolean | Returns or sets whether the slide advances after a specified time. |
| AdvanceTime | number \| undefined | Returns or sets the slide advance time in milliseconds. |
| Duration | number | Returns or sets the transition duration in milliseconds. |
| EntryEffect | [EntryEffect](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/Enumeration/EntryEffect.md) | Returns or sets the entry effect for the slide show transition. |
| Speed | [TransitionSpeed](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/Enumeration/TransitionSpeed.md) | Returns or sets the transition speed. |
