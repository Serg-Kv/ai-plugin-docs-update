# ApiCustomXmlParts

Class representing a custom XML manager, which provides methods to manage custom XML parts in the document.

## Methods

The following table lists the available methods.

| Method | Returns | Description |
| ------ | ------- | ----------- |
| [Add](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiCustomXmlParts/Methods/Add.md) | [ApiCustomXmlPart](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiCustomXmlPart.md) | Adds a new custom XML part to the XML manager. |
| [GetAll](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiCustomXmlParts/Methods/GetAll.md) | [ApiCustomXmlPart](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiCustomXmlPart.md)[] | Returns all custom XML parts from the XML manager. |
| [GetById](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiCustomXmlParts/Methods/GetById.md) | [ApiCustomXmlPart](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiCustomXmlPart.md) \| null | Returns a custom XML part by its ID from the XML manager. |
| [GetByNamespace](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiCustomXmlParts/Methods/GetByNamespace.md) | [ApiCustomXmlPart](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiCustomXmlPart.md)[] | Returns custom XML parts by namespace from the XML manager. |
| [GetClassType](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiCustomXmlParts/Methods/GetClassType.md) | "customXmlParts" | Returns a type of the ApiCustomXmlParts class. |
| [GetCount](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiCustomXmlParts/Methods/GetCount.md) | number | Returns a number of custom XML parts in the XML manager. |
