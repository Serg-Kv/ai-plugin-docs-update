# ApiColor

Represents a color that can be applied to text.

## Methods

The following table lists the available methods.

| Method | Returns | Description |
| ------ | ------- | ----------- |
| [FromJSON](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiColor/Methods/FromJSON.md) | [ApiColor](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiColor.md) \| null | Converts the JSON object into the ApiColor object. |
| [GetClassType](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiColor/Methods/GetClassType.md) | "color" | Returns a type of the ApiColor class. |
| [GetHex](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiColor/Methods/GetHex.md) | string | Gets the HEX string representation of the color. |
| [GetRGB](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiColor/Methods/GetRGB.md) | Object | Gets the RGB components of the color. |
| [GetRGBA](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiColor/Methods/GetRGBA.md) | Object | Gets the RGBA components of the color. |
| [GetThemeName](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiColor/Methods/GetThemeName.md) | [SchemeColorId](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/Enumeration/SchemeColorId.md) \| null | Gets the theme color name if the color is a theme color. |
| [GetTintAndShade](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiColor/Methods/GetTintAndShade.md) | number | Returns the luminance shift applied to the color. |
| [IsThemeColor](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiColor/Methods/IsThemeColor.md) | boolean | Returns true if the color is a theme color. |
| [ToJSON](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiColor/Methods/ToJSON.md) | string | Converts the ApiColor object into the JSON object. |
