# ApiHyperlink

Class representing a Paragraph hyperlink.

## Methods

The following table lists the available methods.

| Method | Returns | Description |
| ------ | ------- | ----------- |
| [GetClassType](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiHyperlink/Methods/GetClassType.md) | "hyperlink" | Returns a type of the ApiHyperlink class. |
| [GetElement](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiHyperlink/Methods/GetElement.md) | [ParagraphContent](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/Enumeration/ParagraphContent.md) \| null \| undefined | Returns the hyperlink element using the position specified. |
| [GetElementsCount](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiHyperlink/Methods/GetElementsCount.md) | number | Returns a number of elements in the current hyperlink. |
| [GetLinkedText](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiHyperlink/Methods/GetLinkedText.md) | string | Returns the hyperlink address. |
| [GetScreenTipText](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiHyperlink/Methods/GetScreenTipText.md) | string | Returns the screen tip text of the hyperlink. |
| [GetTextRange](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiHyperlink/Methods/GetTextRange.md) | [ApiTextRange](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiTextRange.md) \| null | Returns an ApiTextRange object that represents the part of the text contained in the current hyperlink. |
| [SetLink](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiHyperlink/Methods/SetLink.md) | boolean | Sets the hyperlink address. |
| [SetScreenTipText](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiHyperlink/Methods/SetScreenTipText.md) | boolean | Sets the screen tip text of the hyperlink. |
