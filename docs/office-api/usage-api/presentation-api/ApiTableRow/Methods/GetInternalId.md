# GetInternalId

Returns an internal id of the current table row.

## Syntax

```javascript
expression.GetInternalId();
```

`expression` - A variable that represents an [ApiTableRow](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiTableRow.md) class.

## Parameters

This method doesn't have any parameters.

## Returns

string
