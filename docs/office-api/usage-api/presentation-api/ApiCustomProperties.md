# ApiCustomProperties

Class representing custom properties of the document.

## Methods

The following table lists the available methods.

| Method | Returns | Description |
| ------ | ------- | ----------- |
| [Add](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiCustomProperties/Methods/Add.md) | boolean | Adds a custom property to the document with automatic type detection. |
| [Get](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiCustomProperties/Methods/Get.md) | string \| number \| Date \| boolean \| null | Returns the value of a custom property by its name. |
| [GetClassType](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiCustomProperties/Methods/GetClassType.md) | "customProperties" | Returns a type of the ApiCustomProperties class. |
