| [SetFormatScheme](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiTheme/Methods/SetFormatScheme.md) | boolean | Sets the format scheme to the current presentation theme. |
