# ApiLayout

Class representing a slide layout.

## Methods

The following table lists the available methods.

| Method | Returns | Description |
| ------ | ------- | ----------- |
| [AddObject](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiLayout/Methods/AddObject.md) | boolean | Adds an object (image, shape or chart) to the current slide layout. |
| [ClearBackground](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiLayout/Methods/ClearBackground.md) | boolean | Clears the slide layout background. |
| [Copy](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiLayout/Methods/Copy.md) | [ApiLayout](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiLayout.md) \| null | Creates a copy of the specified slide layout object. |
| [Delete](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiLayout/Methods/Delete.md) | boolean | Deletes the specified object from the parent slide master if it exists. |
| [Duplicate](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiLayout/Methods/Duplicate.md) | [ApiLayout](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiLayout.md) \| null | Creates a duplicate of the specified slide layout object, adds the new slide layout to the slide layout collection. |
| [FollowMasterBackground](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiLayout/Methods/FollowMasterBackground.md) | boolean | Sets the master background as the background of the layout. |
| [GetAllCharts](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiLayout/Methods/GetAllCharts.md) | [ApiChart](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiChart.md)[] | Returns an array with all the chart objects from the slide layout. |
| [GetAllDrawings](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiLayout/Methods/GetAllDrawings.md) | [Drawing](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/Enumeration/Drawing.md)[] | Returns an array with all the drawing objects from the slide layout. |
| [GetAllImages](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiLayout/Methods/GetAllImages.md) | [ApiImage](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiImage.md)[] | Returns an array with all the image objects from the slide layout. |
| [GetAllOleObjects](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiLayout/Methods/GetAllOleObjects.md) | [ApiOleObject](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiOleObject.md)[] | Returns an array with all the OLE objects from the slide layout. |
| [GetAllShapes](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiLayout/Methods/GetAllShapes.md) | [ApiShape](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiShape.md)[] | Returns an array with all the shape objects from the slide layout. |
| [GetAllTables](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiLayout/Methods/GetAllTables.md) | [ApiTable](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiTable.md)[] | Returns an array with all tables from the current slide layout. |
| [GetBackground](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiLayout/Methods/GetBackground.md) | [ApiFill](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiFill.md) \| null | Returns the background fill of the current slide layout. |
| [GetClassType](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiLayout/Methods/GetClassType.md) | "layout" | Returns the type of the ApiLayout class. |
| [GetDrawingsByPlaceholderType](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiLayout/Methods/GetDrawingsByPlaceholderType.md) | [Drawing](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/Enumeration/Drawing.md)[] | Returns an array of drawings by the specified placeholder type. |
| [GetLayoutType](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiLayout/Methods/GetLayoutType.md) | [LayoutType](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/Enumeration/LayoutType.md) | Returns the type of the current layout. |
| [GetMaster](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiLayout/Methods/GetMaster.md) | [ApiMaster](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiMaster.md) \| null \| undefined | Returns the parent slide master of the current layout. |
| [GetName](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiLayout/Methods/GetName.md) | string | Returns a name of the current layout. |
| [GetVisitor](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiLayout/Methods/GetVisitor.md) | [ApiPresentationVisitor](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiPresentationVisitor.md) | Returns a visitor object for traversing the drawings and text of the current slide layout. |
| [GroupDrawings](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiLayout/Methods/GroupDrawings.md) | [ApiGroup](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiGroup.md) | Groups an array of drawings in the current layout. |
| [MoveTo](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiLayout/Methods/MoveTo.md) | boolean | Moves the specified layout to a specific location within the same collection. |
| [RemoveObject](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiLayout/Methods/RemoveObject.md) | boolean | Removes objects (image, shape or chart) from the current slide layout. |

| [SetBackground](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiLayout/Methods/SetBackground.md) | boolean | Sets the background to the current slide layout. |
| [SetName](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiLayout/Methods/SetName.md) | boolean | Sets a name to the current layout. |
| [ToJSON](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiLayout/Methods/ToJSON.md) | JSON | Converts the ApiLayout object into the JSON object. |
