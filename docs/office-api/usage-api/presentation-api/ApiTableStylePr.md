# ApiTableStylePr

Class representing a set of formatting properties which shall be conditionally applied to the parts of a table which match the requirement specified on the `Type`.

## Methods

The following table lists the available methods.

| Method | Returns | Description |
| ------ | ------- | ----------- |
| [GetClassType](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiTableStylePr/Methods/GetClassType.md) | "tableStylePr" | Returns a type of the ApiTableStylePr class. |
| [GetTablePr](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiTableStylePr/Methods/GetTablePr.md) | [ApiTablePr](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiTablePr.md) | Returns a set of the table properties which will be applied to all the regions within a table which match the conditional formatting type. |
| [GetType](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiTableStylePr/Methods/GetType.md) | [TableStyleOverrideType](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/Enumeration/TableStyleOverrideType.md) | Returns a type of the current table conditional style. |
| [SetTablePr](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiTableStylePr/Methods/SetTablePr.md) | boolean | Sets the table properties to the current table style properties. |
