# DocumentElement

Any valid element which can be added to the document structure.

## Type

Enumeration

## Values

- [ApiParagraph](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiParagraph.md)

## Example

Add a document element called "paragraph" to the document.

```javascript editor-pptx
// How do I add a paragraph element to a document?

// Add elements to the document.

doc.AddElement(paragraph);
```
