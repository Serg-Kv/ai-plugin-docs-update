# GetClassType

Returns a type of the ApiUnsupported class.

## Syntax

```javascript
expression.GetClassType();
```

`expression` - A variable that represents an [ApiUnsupported](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiUnsupported.md) class.

## Parameters

This method doesn't have any parameters.

## Returns

"unsupported"
