# ApiAnimationEffect

Class representing an animation effect.

## Methods

The following table lists the available methods.

| Method | Returns | Description |
| ------ | ------- | ----------- |
| [Delete](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiAnimationEffect/Methods/Delete.md) | boolean | Deletes the animation effect. |
| [GetClassType](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiAnimationEffect/Methods/GetClassType.md) | "animationEffect" | Returns the type of the ApiAnimationEffect class. |
| [GetDelay](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiAnimationEffect/Methods/GetDelay.md) | number | Returns the delay before the animation effect starts in milliseconds. |
| [GetDuration](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiAnimationEffect/Methods/GetDuration.md) | number | Returns the duration of the animation effect in milliseconds. |
| [GetEffectType](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiAnimationEffect/Methods/GetEffectType.md) | [AnimationEffectType](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/Enumeration/AnimationEffectType.md) \| null | Returns the animation effect type. |
| [GetRepeatCount](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiAnimationEffect/Methods/GetRepeatCount.md) | number | Returns the repeat count for the animation effect. |
| [GetShape](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiAnimationEffect/Methods/GetShape.md) | [ApiDrawing](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiDrawing.md) \| null | Returns the animated drawing object. |
| [GetTriggerType](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiAnimationEffect/Methods/GetTriggerType.md) | [AnimationTriggerType](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/Enumeration/AnimationTriggerType.md) | Returns the trigger type for the animation effect. |
| [MoveTo](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiAnimationEffect/Methods/MoveTo.md) | boolean | Moves the animation effect to the specified position in the sequence. |
| [SetDelay](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiAnimationEffect/Methods/SetDelay.md) | boolean | Sets the delay before the animation effect starts in milliseconds. |
| [SetDuration](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiAnimationEffect/Methods/SetDuration.md) | boolean | Sets the duration of the animation effect in milliseconds. |
| [SetRepeatCount](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiAnimationEffect/Methods/SetRepeatCount.md) | boolean | Sets the repeat count for the animation effect. |
| [SetTriggerType](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiAnimationEffect/Methods/SetTriggerType.md) | boolean | Sets the trigger type for the animation effect. |
