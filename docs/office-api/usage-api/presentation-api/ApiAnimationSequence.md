# ApiAnimationSequence

Class representing an animation sequence (main sequence or interactive sequence).

## Methods

The following table lists the available methods.

| Method | Returns | Description |
| ------ | ------- | ----------- |
| [AddEffect](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiAnimationSequence/Methods/AddEffect.md) | [ApiAnimationEffect](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiAnimationEffect.md) \| null | Adds an animation effect to the sequence. |
| [GetClassType](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiAnimationSequence/Methods/GetClassType.md) | "animationSequence" | Returns the type of the ApiAnimationSequence class. |
| [GetCount](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiAnimationSequence/Methods/GetCount.md) | number | Returns the number of effects in the sequence. |
| [GetEffect](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiAnimationSequence/Methods/GetEffect.md) | [ApiAnimationEffect](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiAnimationEffect.md) \| null | Returns the effect at the specified index. |
| [RemoveAllEffects](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiAnimationSequence/Methods/RemoveAllEffects.md) | boolean | Removes all effects from the sequence. |
