Class representing a path command.

## Methods

The following table lists the available methods.

| Method | Returns | Description |
| ------ | ------- | ----------- |

| [GetStartAngle](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiPathCommand/Methods/GetStartAngle.md) | string \| null | Returns the start angle of the arc. |
| [GetSweepAngle](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiPathCommand/Methods/GetSweepAngle.md) | string \| null | Returns the sweep angle of the arc. |
| [GetType](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiPathCommand/Methods/GetType.md) | [PathCommandType](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/Enumeration/PathCommandType.md) | Returns the type of the current path command. |
| [GetWR](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiPathCommand/Methods/GetWR.md) | string \| null | Returns the width radius of the arc. |
| [GetX](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiPathCommand/Methods/GetX.md) | string \| null | Returns the X coordinate for the "moveTo"/"lineTo" path commands. |

| [GetX2](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiPathCommand/Methods/GetX2.md) | string \| null | Returns the X coordinate of the end point for the cubic Bezier curves. |
| [GetY](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiPathCommand/Methods/GetY.md) | string \| null | Returns the Y coordinate for the "moveTo"/"lineTo" path commands. |
| [GetY0](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiPathCommand/Methods/GetY0.md) | string \| null | Returns the Y coordinate of the first control point for the Bezier curves. |
| [GetY1](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiPathCommand/Methods/GetY1.md) | string \| null | Returns the Y coordinate of the second control point for the cubic Bezier curves. |
| [GetY2](https://api.onlyoffice.com/ai-plugin-docs-update/docs/office-api/usage-api/presentation-api/ApiPathCommand/Methods/GetY2.md) | string \| null | Returns the Y coordinate of the end point for the cubic Bezier curves. |
