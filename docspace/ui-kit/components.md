# Components

The composites built from the UI components for the portal's screens. Of these, the providers are public; the rest need a portal.

## Overview

The groups are:

| Group | Description |
| --- | --- |
| [AI Chat](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/ui-kit/components/ai-chat.md) | A conversation with the portal's AI models, about the files and rooms the user is working in. |
| [AI Settings](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/ui-kit/components/ai-settings.md) | The portal's AI settings screens, from `ai-agent/settings`. |
| [Files](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/ui-kit/components/files.md) | The Files section as the portal draws it: a header, the filter bar and the rows of the caller's personal folder. |
| [Rooms](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/ui-kit/components/rooms.md) | The Rooms section: the active rooms the caller can see, with a header, the filter bar and the rows. |
| [Forms](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/ui-kit/components/forms.md) | The Forms section: the form-filling rooms the caller can see, with a header, the filter bar and the rows. |
| [Uploader](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/ui-kit/components/uploader.md) | Uploader is a file upload component that supports chunked uploads, folder uploads, and file size validation. |
| [Document Editor](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/ui-kit/components/document-editor.md) | DocumentEditor wraps the \`@onlyoffice/document-editor-react\` component, embedding an ONLYOFFICE Document Server editor into the UI. |
| [Selectors](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/ui-kit/components/selectors.md) | The portal's pickers: a panel that lists files, rooms, people, groups, AI agents or MCP servers from a portal and hands back what the user chose. |
| [Providers](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/ui-kit/components/providers.md) | The providers an application mounts above the components. |
| [Errors](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/ui-kit/components/errors.md) | The full-page states the portal shows when a request fails: access denied, not found, offline, unavailable, an expired link. |
