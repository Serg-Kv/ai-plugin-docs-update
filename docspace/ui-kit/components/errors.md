# Errors

The full-page states the portal shows when a request fails: access denied, not found, offline, unavailable, an expired link.

## Overview

The following components are available:

| Page | Description |
| --- | --- |
| [AccessRestricted](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/ui-kit/components/errors/access-restricted.md) | Access restricted error page. |
| [Error401](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/ui-kit/components/errors/error-401.md) | Unauthorized error page (401). |
| [Error403](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/ui-kit/components/errors/error-403.md) | Forbidden error page (403). |
| [Error404](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/ui-kit/components/errors/error-404.md) | Not Found error page (404). |
| [ErrorInvalidLink](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/ui-kit/components/errors/error-invalid-link.md) | Invalid link error page. |
| [ErrorOffline](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/ui-kit/components/errors/error-offline.md) | Offline error page. |
| [ErrorUnavailable](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/ui-kit/components/errors/error-unavailable.md) | Unavailable error page. |
