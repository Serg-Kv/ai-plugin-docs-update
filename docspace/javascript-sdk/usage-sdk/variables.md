# Variables

Exported constants: the default frame configuration, the iframe name prefix, the CSP validation endpoint and the error messages the SDK shows.

## Overview

The following constants are available:

| Constant | Description |
| --- | --- |
| [`connectErrorText`](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/javascript-sdk/usage-sdk/variables/connectErrorText.md) | Error message passed to [TFrameEvents.onAppError](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/javascript-sdk/usage-sdk/type-aliases/TFrameEvents.md#onAppError) when a method is called before the postMessage channel is established (i.e. before the first valid message from the iframe). |
| [`CSPApiUrl`](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/javascript-sdk/usage-sdk/variables/CSPApiUrl.md) | The ONLYOFFICE Apps CSP validation endpoint. |
| [`cspErrorText`](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/javascript-sdk/usage-sdk/variables/cspErrorText.md) | Error message shown when the host domain is not in the ONLYOFFICE Apps CSP allowlist. |
| [`defaultConfig`](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/javascript-sdk/usage-sdk/variables/defaultConfig.md) | The default configuration applied to every frame before user overrides. |
| [`FRAME_NAME`](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/javascript-sdk/usage-sdk/variables/FRAME_NAME.md) | The prefix for iframe `name` attribute. |
| [`TOKEN_REFRESH_LEAD_MS`](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/javascript-sdk/usage-sdk/variables/TOKEN_REFRESH_LEAD_MS.md) | — |
