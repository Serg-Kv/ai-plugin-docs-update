# TBannerDisplaying

String literal union of all [HeaderBannerDisplaying](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/javascript-sdk/usage-sdk/enumerations/HeaderBannerDisplaying.md) values.

Accepted by [TFrameConfig.showHeaderBanner](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/javascript-sdk/usage-sdk/type-aliases/TFrameConfig.md#showHeaderBanner).
Using the [HeaderBannerDisplaying](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/javascript-sdk/usage-sdk/enumerations/HeaderBannerDisplaying.md) enum constants is preferred.

```ts
type TBannerDisplaying = `${HeaderBannerDisplaying}`;
```
