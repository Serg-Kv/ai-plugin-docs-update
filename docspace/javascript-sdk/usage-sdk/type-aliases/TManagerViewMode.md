# TManagerViewMode

String literal union of all [ManagerViewMode](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/javascript-sdk/usage-sdk/enumerations/ManagerViewMode.md) values.

Accepted by [TFrameConfig.viewAs](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/javascript-sdk/usage-sdk/type-aliases/TFrameConfig.md#viewAs) in [SDKMode.Manager](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/javascript-sdk/usage-sdk/enumerations/SDKMode.md#Manager) mode.
Using the [ManagerViewMode](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/javascript-sdk/usage-sdk/enumerations/ManagerViewMode.md) enum constants is preferred.

```ts
type TManagerViewMode = `${ManagerViewMode}`;
```
