# TEditorType

String literal union of all [EditorType](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/javascript-sdk/usage-sdk/enumerations/EditorType.md) values.

Accepted by [TFrameConfig.editorType](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/javascript-sdk/usage-sdk/type-aliases/TFrameConfig.md#editorType) and [TFrameConfig.type](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/javascript-sdk/usage-sdk/type-aliases/TFrameConfig.md#type).
Using the [EditorType](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/javascript-sdk/usage-sdk/enumerations/EditorType.md) enum constants is preferred.

```ts
type TEditorType = `${EditorType}`;
```
