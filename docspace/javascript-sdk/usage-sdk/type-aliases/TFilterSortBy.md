# TFilterSortBy

String literal union of all [FilterSortBy](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/javascript-sdk/usage-sdk/enumerations/FilterSortBy.md) values.

Accepted by [TFrameFilter.sortBy](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/javascript-sdk/usage-sdk/type-aliases/TFrameFilter.md#sortBy).
Using the [FilterSortBy](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/javascript-sdk/usage-sdk/enumerations/FilterSortBy.md) enum constants is preferred.

```ts
type TFilterSortBy = `${FilterSortBy}`;
```
