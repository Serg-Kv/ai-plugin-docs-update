# TTheme

String literal union of all [Theme](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/javascript-sdk/usage-sdk/enumerations/Theme.md) values.

Accepted by [TFrameConfig.theme](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/javascript-sdk/usage-sdk/type-aliases/TFrameConfig.md#theme) to control the iframe color scheme.
Using the [Theme](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/javascript-sdk/usage-sdk/enumerations/Theme.md) enum constants is preferred.

```ts
type TTheme = `${Theme}`;
```
