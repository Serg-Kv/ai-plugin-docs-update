# TFilterSortOrder

String literal union of all [FilterSortOrder](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/javascript-sdk/usage-sdk/enumerations/FilterSortOrder.md) values.

Accepted by [TFrameFilter.sortOrder](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/javascript-sdk/usage-sdk/type-aliases/TFrameFilter.md#sortOrder).
Using the [FilterSortOrder](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/javascript-sdk/usage-sdk/enumerations/FilterSortOrder.md) enum constants is preferred.

```ts
type TFilterSortOrder = `${FilterSortOrder}`;
```
