# Type Aliases

Configuration, event, filter and data shapes exchanged with the embedded frame. Most integrations only need `TFrameConfig` and `TFrameEvents`; the remaining types describe what the instance methods accept and return.

## Overview

The following types are available:

| Type | Description |
| --- | --- |
| [`TAppReadyPayload`](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/javascript-sdk/usage-sdk/type-aliases/TAppReadyPayload.md) | Payload of [TFrameEvents.onAppReady](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/javascript-sdk/usage-sdk/type-aliases/TFrameEvents.md#onAppReady). |
| [`TAuthError`](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/javascript-sdk/usage-sdk/type-aliases/TAuthError.md) | Payload of [TFrameEvents.onAuthError](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/javascript-sdk/usage-sdk/type-aliases/TFrameEvents.md#onAuthError). |
| [`TAuthErrorCode`](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/javascript-sdk/usage-sdk/type-aliases/TAuthErrorCode.md) | Failure categories reported through [TFrameEvents.onAuthError](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/javascript-sdk/usage-sdk/type-aliases/TFrameEvents.md#onAuthError) in OAuth mode. |
| [`TBannerDisplaying`](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/javascript-sdk/usage-sdk/type-aliases/TBannerDisplaying.md) | String literal union of all [HeaderBannerDisplaying](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/javascript-sdk/usage-sdk/enumerations/HeaderBannerDisplaying.md) values. |
| [`TCreatedBy`](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/javascript-sdk/usage-sdk/type-aliases/TCreatedBy.md) | User reference in file/folder/room metadata. |

| [`TEditorCustomization`](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/javascript-sdk/usage-sdk/type-aliases/TEditorCustomization.md) | Editor customization options passed via [TFrameConfig.editorCustomization](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/javascript-sdk/usage-sdk/type-aliases/TFrameConfig.md#editorCustomization). |
