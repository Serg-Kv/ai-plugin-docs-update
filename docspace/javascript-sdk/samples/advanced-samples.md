# Advanced samples

These samples show how to combine ONLYOFFICE Apps Embed SDK calls into complete, real-world integrations. Each one builds on the basics covered in [Basic samples](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/javascript-sdk/samples/basic-samples.md) and targets a specific use case.

## Security and access

| Sample | Description |
| --- | --- |
| [Authorization](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/javascript-sdk/samples/advanced-samples/authorization.md) | Log in to an ONLYOFFICE Apps account using email and password hash. |
| [Two-factor authentication](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/javascript-sdk/samples/advanced-samples/two-factor-authentication.md) | Verify users with a phone code before granting ONLYOFFICE Apps access. |
