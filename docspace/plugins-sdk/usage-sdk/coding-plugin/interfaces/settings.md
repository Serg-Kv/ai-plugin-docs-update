# Settings

Interfaces for configuring plugin settings displayed in the ONLYOFFICE Apps admin and user settings panels.

Implement `ISettingsPlugin` and use `ISettings` to describe each configurable field.

## Overview

Settings interfaces:

| Interface | Description |
| --- | --- |
| [`ISettings`](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/plugins-sdk/usage-sdk/coding-plugin/interfaces/settings/ISettings.md) | Defines the administrator or owner settings block that is embedded in the side panel of the plugin. |
