# Enums

Enumerations for actions, component types, events, file types, security permissions, room types and other SDK-wide constants.

Import and use these typed constants in place of raw strings throughout your plugin.

## Overview

Available enumerations:

| Enum | Description |
| --- | --- |
| [`Actions`](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/plugins-sdk/usage-sdk/coding-plugin/enums/Actions.md) | A collection of events that will be processed on the portal side. |
| [`Components`](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/plugins-sdk/usage-sdk/coding-plugin/enums/Components.md) | Defines the available UI component. |
| [`Devices`](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/plugins-sdk/usage-sdk/coding-plugin/enums/Devices.md) | Defines the supported device types. |
| [`Events`](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/plugins-sdk/usage-sdk/coding-plugin/enums/Events.md) | Defines the supported event types for the plugin system. |
| [`Files`](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/plugins-sdk/usage-sdk/coding-plugin/enums/Files.md) | Enumerations for file types, supported extensions, and security permissions. |
| [`Plugins`](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/plugins-sdk/usage-sdk/coding-plugin/enums/Plugins.md) | Enumerations for plugin status and supported locales. |
| [`Rooms`](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/plugins-sdk/usage-sdk/coding-plugin/enums/Rooms.md) | Enumerations for ONLYOFFICE Apps room types and search scopes. |
| [`Section`](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/plugins-sdk/usage-sdk/coding-plugin/enums/Section.md) | Defines the portal sections in which an article navigation item can appear. |
| [`Security`](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/plugins-sdk/usage-sdk/coding-plugin/enums/Security.md) | Defines the supported room/folder security parameters. |
| [`SelectorType`](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/plugins-sdk/usage-sdk/coding-plugin/enums/Selector.md) | Defines the types of selector components that can be rendered. |
| [`UserRole`](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/plugins-sdk/usage-sdk/coding-plugin/enums/UserRole.md) | Defines the supported user types, named as the portal names them. |
| [`UsersType`](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/plugins-sdk/usage-sdk/coding-plugin/enums/UsersType.md) | Defines the supported user types. |
| [`FilterType`](https://api.onlyoffice.com/ai-plugin-docs-update/docspace/plugins-sdk/usage-sdk/coding-plugin/enums/Utility.md) | Enum for filter type used in file selectors. |
